# Carryover

**Will your queued jobs survive the deploy?**

Carryover catches deploys that break jobs already waiting in your queue:
renamed job classes, new properties without defaults, narrowed types,
removed enum cases, and more. It checks recorded job payloads against
your new code before you ship.

> 🚧 Work in progress. Not ready for use yet.
